## Сравнительная матрица: Qorgau DLP v2.0 vs iBatyr Monitor 5.6

| Возможность | iBatyr Monitor 5.6 | Qorgau DLP v2.0 (Rust) | Преимущество Qorgau |
|---|---|---|---|
| **Стек и потребление RAM** | Тяжёлый проприетарный сервер + ОС | Rust сервер (~24 МБ RAM) + агент (2.94 МБ / ~6.6 МБ RAM) | В 5–10× легче на агентах и сервере |
| **Веб-консоль SOC** | Классический интерфейс | Современный Dark/Light SOC Command Center, `Ctrl+K`, живые графики, PDF-печать | Быстрее, эргономичнее, 1 клик до любого ПК |
| **Стандартные профили** | Пресеты | 5 встроенных эталонных профилей + выбор прямо из таблицы Агентов + массовое назначение | Мгновенный push по WebSocket без перезагрузки |
| **Квадратор Live + Водяные знаки** | Есть | Есть (сетка Live + нативные GDI/Win32 водяные знаки поверх окон) | Прозрачный оверлей без лагов и нагрузки |
| **Менеджер ВНИ (USB Whitelist/Eject)** | Есть | Есть (`VID`/`PID`/`Serial` + принудительное извлечение) | Работает из коробки на чистом Win32 |
| **Блокировка ПО и сайтов** | Есть | Есть (`TerminateProcess` + управляемый `hosts`) | Мгновенная синхронизация правил |
| **Краулер ПДн и Инвентаризация** | Есть | Есть (встроенная математика ИИН/БИН РК, Luhn, IBAN KZ) | Локализация под стандарты РК |
| **Комплаенс РК и Legal Hold** | Базовый | ТК РК ст. 23 (fail-closed), Закон о ПДн №94-V, SHA-256 аудит, Legal Hold | Готовые официальные отчёты и верификация |
| **Установочный ISO Appliance** | Поставляется | Воспроизводимый оффлайн Debian 12 ISO (`935 МБ`, BIOS+UEFI) | Полный контроль над сборкой и исходным кодом |

## Дорожная карта развития (Вариант C — Enterprise Scale)

- [x] **Интеграция с Active Directory / LDAP** — синхронизация оргструктуры, отделов, должностей и корпоративных доменов (`/directory/settings`, `/directory/import`, `/directory/users`).
- [x] **Почтовый перехват (SMTP / IMAP / Outlook Add-in)** — приём и DLP-анализ писем и вложений в реальном времени с блокировкой и инцидентами (`/mail/events`).
- [ ] **Кроссплатформенные агенты** — Linux (`x86_64` / Astra Linux / Ubuntu) и macOS на единой кодовой базе `qorgau-common`.
- [x] **SIEM-коннектор (CEF / Syslog RFC 5424 / Webhook)** — потоковая отправка алертов в QRadar, Splunk, Wazuh, MaxPatrol SIEM + управление и тест в веб-консоли (`/settings/siem`).
- [x] **Детекция аномалий (UEBA)** — выявление ночной активности, массового копирования/USB и резкого всплеска инцидентов относительно 14-дневного базового профиля (`/ueba/anomalies`).
- [x] **TLS / HTTPS из коробки** — авто-генерация самоподписанного сертификата (`/etc/qorgau/tls/qorgau.crt`) и HTTPS (порт 443) в ISO Appliance.
