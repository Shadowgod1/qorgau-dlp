## 5 видов отчётов в Центре отчётов (`/reports`)

1. **Инциденты DLP** — сводка KPI, столбчатая диаграмма по каналам утечек, кольцевая диаграмма по серьёзности, топ нарушителей.
2. **Сотрудники и УРВ** — сводная ведомость по персоналу: Risk Score, количество инцидентов, суммарное активное время и процент продуктивности.
3. **Парк агентов** — покрытие защитой (онлайн/офлайн), реестр версий ОС и назначенных профилей.
4. **ПДн и ВНИ (USB)** — сводка открытых находок Краулера ПДн на дисках + актуальный реестр разрешённых/заблокированных USB-носителей.
5. **Комплаенс РК** — интерактивная шкала соответствия (0–100%) требованиям нормативно-правовых актов Республики Казахстан.

## Форматы выгрузки

| Формат | Назначение |
|---|---|
| **Печать / PDF** | Встроенная чистая печатная вёрстка (`@media print`) с официальной шапкой отчёта и датой формирования — сохраняется в PDF за 1 клик. |
| **Инциденты XLSX / CSV / JSON** | Выгрузка журнала инцидентов за выбранный период (Сегодня / 7д / 30д / 90д / Год / произвольный диапазон). |
| **CDR Excel / CSV** | Детальные записи активности (Call/Activity Detail Records) для передачи в SIEM или следственные органы. |
| **УРВ Excel** | Табель учёта рабочего времени и продуктивности сотрудников для HR и руководителей подразделений. |

## Правовая база Республики Казахстан

> [!info] Встроенные механизмы комплаенса
> - **Закон РК №94-V «О персональных данных и их защите»:** автоматическое выявление ИИН/БИН/карт/IBAN, краулер неконтролируемых ПДн на дисках, маскирование данных для роли `viewer`.
> - **Трудовой кодекс РК, ст. 23:** модули скрытого аудио- и видеонаблюдения (`mod_microphone`, `mod_webcam`) строго **отключены по умолчанию (fail-closed)** и сопровождаются явным предупреждением при включении.
> - **Приказ МЦРИАП / ЕТ ИБ (Приказ №410):** неизменяемый журнал аудита действий операторов с SHA-256 хэш-цепочкой, хранение теневых копий и **Legal Hold** для сохранности доказательной базы.
