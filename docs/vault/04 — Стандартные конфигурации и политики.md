# ⚙️ Стандартные конфигурации и политики DLP

← [[03 — Windows-агент (Rust)]] | Далее: [[05 — Активная защита (USB ВНИ, ПО, Веб, Краулер)]]

В Qorgau DLP v2.0 администратор может управлять поведением разных групп компьютеров через **профили конфигураций** (раздел **Конфигурации** `/configs`) и мгновенно переключать их прямо в таблице **Агенты** (`/agents`) — изменения доставляются агентам по WebSocket без перезапуска службы.

---

## 5 встроенных стандартных профилей (авто-сид `0004_standard_configs.sql`)

| Профиль | Скриншоты | Водяной знак | USB ВНИ | Блок ПО / Сайтов | Краулер ПДн | Назначение |
|---|---|---|---|---|---|---|
| **Стандартный (Офис)** | 60 сек | OFF | Аудит | OFF / OFF | OFF | Базовый сбалансированный профиль для большинства офисных ПК |
| **Усиленный ИБ (Бухгалтерия / Финансы)** | 30 сек | ON (26%) | **Whitelist (Eject)** | OFF / **ON** | **ON** | Отделы с ПДн, ИИН/БИН, 1С, клиент-банками |
| **Максимальная защита (Гриф ДСП)** | 20 сек | ON (32%) | **Whitelist (Eject)** | **ON** / **ON** | **ON** | Критичные рабочие станции, КТ/ДСП, высший уровень контроля |
| **Только УРВ (Учёт рабочего времени)** | OFF | OFF | OFF | OFF / OFF | OFF | Деликатный контроль продуктивности: только сессии, ПО, веб и инвентарь |
| **Удалённый сотрудник (VPN / Home Office)** | 45 сек | ON (22%) | Аудит | OFF / **ON** | OFF | Защита от фото экрана дома + контроль мессенджеров, файлов и Tor/RDP |

> [!warning] Безопасность по умолчанию (Fail-Closed)
> Во всех 5 стандартных профилях `mod_microphone = OFF` и `mod_webcam = OFF`. Включить их можно только осознанно вручную при редактировании профиля во вкладке «Краулер и Аудио/Видео».

---

## Как назначать конфигурации

1. **Точечно из таблицы Агенты (`/agents`)**: выберите нужный профиль в выпадающем списке колонки *«Конфигурация (профиль)»* — агент обновится немедленно.
2. **Массово**: отметьте чекбоксами группу ПК в таблице **Агенты**, выберите профиль в верхней панели и нажмите *«Применить ко всем»*.
3. **Из карточки конфигурации (`/configs`)**: нажмите *«Назначить ПК»* на нужной карточке профиля.
4. **Дублирование**: нажмите иконку копирования на любом стандартном профиле, чтобы создать его кастомную вариацию для конкретного отдела.

## Встроенный движок DLP-политик (`qorgau-common/src/dlp.rs`)

Движок автоматически проверяет буфер обмена, мессенджеры, OCR скриншотов, локальные файлы и находки Краулера ПДн на:
- **ИИН РК** (12 цифр + математическая проверка контрольного разряда по весам 1..11 и 3..11);
- **БИН РК** (12 цифр + проверка признака юридического лица);
- **Банковские карты** (16 цифр + проверка алгоритма Луна);
- **IBAN Казахстана** (`KZ` + 18 символов);
- **Грифы секретности / ДСП / Коммерческая тайна** (на русском и казахском языках);
- **Пользовательские Regex-правила** из раздела **Настройки → Политики DLP** (`/settings`).
